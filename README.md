## 1. 브랜드 아이덴티티

```
브랜드명
GlowSip(가상브랜드)

브랜드 설명
바쁜 현대인을 위한 프리미엄 비타민 에너지 드링크 브랜드. 짧은 휴식만으로도 활력을 되찾을 수 있다는 브랜드 경험을 제공한다.

타겟
- 20~30대 직장인 
- 대학생 및 취업 준비생
- 업무와 학업으로 피로를 자주 느끼는 사람

톤앤매너
- 밝고 세련된 프리미엄 광고 감성
- 미니멀하고 감각적인 영상미
- 희망적이고 에너지 넘치는 분위기

USP (차별점)
단순한 에너지 음료가 아니라 '지친 순간을 빛나는 순간으로 바꾸는 경험'을 전달하는 감성 중심 브랜드.

핵심 메시지
"한 모금으로, 오늘을 빛내다."

광고 목적
인지
```
